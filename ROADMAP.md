# Roadmap

Esse roadmap lista melhorias futuras para o Sistema de Rotina Escolar PROATI.

## Prioridade baixa

### Backup guiado

Melhorar a experiência de exportação e importação com mensagens mais pra frentex.

### Tutorial para outros PROATIs

Acho que seria daora um guia rápido com prints explicando como usar o sistema no dia a dia.

De qualquer forma são usuários que já devem ter um conhecimento mínimo ali, mas por questões de UX poderiamos ver isso.

### Criar uma página de links importantes

Me parece muito útil adicionar os links do PADLET / Arquivos / Vídeos (iframes) úteis PROATEC.

## Fora do escopo por enquanto

- Login e controle por usuário.
- Banco remoto e sincronização online.
- Painel administrativo.

🤓☝️ Essas funcionalidades podem ser úteis no futuro se a seducsp achar interessante (e se gostarem do meu projeto), mas aumentam a complexidade. O foco atual é manter o projeto simples, estático e fácil de publicar.

## Concluído
